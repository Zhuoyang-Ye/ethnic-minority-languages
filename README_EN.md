# Minority Languages Academy (Multi-Ethnic Language Learning Platform)

[English](README_EN.md) | [中文](README.md)

A personal interactive learning platform for Yi (Nuosu), Tibetan, Lisu, Uyghur, and Mongolian. The learning pedagogy draws inspiration from Babbel: bite-sized lessons, conversation-centered, explained in Chinese, active recall exercises, and spaced repetition. All course stages are fully implemented with zero placeholder or empty lessons.

## Getting Started

**Running locally (recommended / simplest)**: Double-click `index.html` to open it in your browser. No internet connection or installation required.

The "Read Aloud" practice uses your microphone. If the browser restricts microphone access when opening local files directly via `file://`, run the following in this folder:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

**Deploying to GitHub Pages (mobile-friendly)**: In your repository, go to **Settings → Pages → Build and deployment**. Under **Source**, select **Deploy from a branch**, choose the `main` branch, and set the folder to `/ (root)`. The site will be accessible after a minute or two.

## Where Progress is Saved

All study progress and review history are stored in the current browser's `localStorage` and are never uploaded to any remote server. Before switching browsers, moving to a new device, or clearing browser cache/data, export a JSON file via **Settings → Backup Progress** (`设置 → 进度备份`), which can later be imported.

## Modifying or Adding Lessons

All lesson texts are located in `data/<language>/stageN.js` as standard JavaScript objects. Changes take effect immediately upon refreshing the page. For schema explanations, instructions on adding new lessons, and linking audio recordings, see [docs/content-guide.md](docs/content-guide.md).

After editing, open `tests.html` in your browser. It verifies character legality, automatic transliteration consistency, tokenization and word-by-word gloss alignment, gloss consistency, and end-to-end exercise simulation across all five languages. A `PASS` in the page title confirms that all tests have succeeded.
