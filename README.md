# 彝藏语学堂

一个自用的彝语、藏语学习网站。学习方式借鉴 Babbel：短课、以会话为中心、用中文讲解、主动回忆练习、间隔复习。

| | 彝语 | 藏语 |
| --- | --- | --- |
| 方言 | 北部方言 · 凉山彝语（诺苏话） | 卫藏方言 · 拉萨话（口语） |
| 文字 | 规范彝文（音节文字）＋ 彝文拼音 | 藏文 ＋ 威利转写 ＋ 简易注音 |
| 已有课程 | 文字与发音 5 课，入门会话（A1）7 课 | 文字与发音 6 课，入门会话（A1）8 课 |
| 规划中 | A2 生活与农事 13 课，B1 文化与口头传统 8 课 | A2 日常生活 8 课，B1 语言与文化 6 课 |

学习框架、每课结构、复习算法和学习计划见 [docs/framework.md](docs/framework.md)。

## 怎么打开

**在本机用（最简单）**：双击 `index.html`，用浏览器打开就行。不需要联网，也不需要安装任何东西。

「跟读」录音要用麦克风。如果直接打开文件时浏览器不让录音，就在这个文件夹里运行：

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

**放到 GitHub Pages 上（手机也能用）**：仓库的 Settings → Pages → Build and deployment，Source 选「Deploy from a branch」，分支选 `main`、目录选 `/ (root)`，保存后过一两分钟就能访问。

注意：

- 免费账号只能从**公开**仓库发布 Pages。私有仓库要 GitHub Pro 或 Team 等付费方案才能发布。
- 即使仓库是私有的，Pages 网站本身仍然**任何人都能访问**。只有 GitHub Enterprise Cloud 的组织才能给 Pages 设访问权限。
- 页面加了 `noindex`，搜索引擎一般不会收录，但知道网址的人都能打开。
- 公开之前请先看下面的「版权」一节。

## 学习进度保存在哪里

进度和复习记录都保存在当前浏览器的 localStorage 里，不会上传到任何地方。换浏览器、换设备或清理浏览器数据之前，在「设置 → 进度备份」里导出一个 JSON 文件，之后再导入。本机打开的版本和 GitHub Pages 上的版本是两个不同的网址，进度也不互通。

## 修改或增加课程

课文都在 `data/<语言>/stageN.js` 里，是普通的 JavaScript 对象，改完刷新页面就能看到。字段说明、藏文注音规则、怎么加课和录音，见 [docs/content-guide.md](docs/content-guide.md)。

改完以后用浏览器打开 `tests.html`，它会检查以下几项：

- 藏文威利转写和程序自动转写是否一致；
- 每句话的分词、逐词注释、注音段数是否对得上；
- 同一个词在不同课里的释义是否一致；
- 每一课生成的练习题是否都有且只有一个正确答案；
- 模拟把每一课从头做到尾。

页面标题显示 `PASS` 就说明全部通过。

## 内容状态（使用前请先读）

- 这些内容是 AI 整理和编写的，**还没有经过母语者或老师审核**。适合作为入门框架，发音和用法请以真人和正式教材为准。
- **彝语会话**取自《凉山彝语会话六百句》（李民、马明著，四川民族出版社，1981）BabelStone 网站英译本，大部分句子原样使用，部分有删节。只有标了「改编」的 2 句是替换词语改写的，未经核对。
- **藏语会话**是本站编写的常用句，拼写对照过词典和教材。注音是简化的拉萨话读音，**不标声调**，和其他教材的写法可能不同。比如 ག 有的书写作 g，本站写作 kh。
- **没有真人录音**。可以用「跟读」录下自己的发音对比。外部有声资源见课程页的「学习资源」。有了录音以后，可以按 [docs/content-guide.md](docs/content-guide.md) 的方法接进来。
