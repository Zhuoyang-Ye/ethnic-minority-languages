# 彝藏语学堂（多民族语言学习站）

一个自用的彝语、藏语、傈僳语、维吾尔语、蒙古语互动学习网站。学习方式借鉴 Babbel：短课、以会话为中心、用中文讲解、主动回忆练习、间隔复习。所有阶段课程均已完整实现，无「规划中」空壳课。

## 怎么打开

**在本机用（最简单）**：双击 `index.html`，用浏览器打开就行。不需要联网，也不需要安装任何东西。

「跟读」录音要用麦克风。如果直接打开文件时浏览器不让录音，就在这个文件夹里运行：

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

**放到 GitHub Pages 上（手机也能用）**：仓库的 Settings → Pages → Build and deployment，Source 选「Deploy from a branch」，分支选 `main`、目录选 `/ (root)`，保存后过一两分钟就能访问。

## 学习进度保存在哪里

进度和复习记录都保存在当前浏览器的 localStorage 里，不会上传到任何地方。换浏览器、换设备或清理浏览器数据之前，在「设置 → 进度备份」里导出一个 JSON 文件，之后再导入。

## 目录结构

```

assets/fonts/           Noto Sans Yi 彝文字体子集（SIL OFL 1.1，许可证见 OFL.txt）
js/core.js              课程注册、五种文字自动转写与分词、复习算法、进度存储
js/yi-syllables.js      1165 个彝文字符 → 拼音对照表（由 tools/gen_yi_syllables.py 生成）
js/exercises.js         练习题生成和答题播放器
js/app.js               页面、各语言文字表与转换工具、路由
data/yi/                彝语：课程总览、语音资料、stage0–stage3（33 课）
data/bo/                藏语：课程总览、字母表、stage0–stage3（28 课）
data/lisu/              傈僳语：课程总览、富能仁字母表、stage0–stage2（10 课）
data/ug/                维吾尔语：课程总览、32 字母表、stage0–stage2（10 课）

```

## 修改或增加课程

课文都在 `data/<语言>/stageN.js` 里，是普通的 JavaScript 对象，改完刷新页面就能看到。字段说明和怎么加课、接录音，见 [docs/content-guide.md](docs/content-guide.md)。

改完以后用浏览器打开 `tests.html`，它会检查全部五门语言的字符合法性、自动转写一致性、分词与逐词注释对齐、词义一致性以及练习题模拟通关。页面标题显示 `PASS` 就说明全部通过。
